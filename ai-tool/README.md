# مدقق الديون (واتساب) — محل الباشمهندس

يقرأ محادثة واتساب (ملف تصدير، أو صورًا ورسائل منسوخة)، ويجد آخر إقفال للحساب بنفسه، ويحسب دين العميل، ويكتب الحساب النهائي بصيغة آلة المحل الحاسبة، ويتعلّم من تصحيحاتك.

| الملف | الوظيفة |
|---|---|
| `public/index.html` · `style.css` | الصفحة |
| `public/app.js` | الواجهة (الإدخال، العرض، التصحيح) |
| `public/core.js` | المنطق: قراءة التصدير، والحساب، والتكرار، ومطابقة الكشف (مغطى بالاختبارات) |
| `lib/ai.js` | **التواصل مع Claude**: القواعد، وشكل الرد، والنماذج، والتكلفة |
| `netlify/edge-functions/analyze.js` | `/api/analyze` على Netlify (المفتاح محفوظ هنا فقط) |
| `netlify/functions/store.mjs` | `/api/store`: حفظ التعليم في Netlify Blobs |
| `local/server.mjs` | الأداة نفسها على الحاسوب (Claude، أو Ollama دون إنترنت) |
| `test/` | `npm test` |

## المدخلات
- ملف تصدير واتساب (`.zip` مع الوسائط، أو `.txt`)، **أو**
- **صور ولقطات شاشة**: اخترها، أو الصقها (Ctrl+V / لصق)، أو اسحبها إلى الصفحة. ويمكن إضافة **رسائل منسوخة** من واتساب في الخانة النصية.
  تُحسب الصور من «المحل» افتراضيًا (اضغط «صور» في الخطوة ٢ إن كانت من العميل)، وتُرتَّب حسب وقت اللقطة.

## يفهم المحادثة ولا يبحث عن كلمة بعينها
لا يلزم كتابة أي كلمة. تقرأ الأداة آخر المحادثة (النص وما في الصور) كما يقرؤها المحاسب، وتحدّد **آخر إقفال للحساب**:
آلة حاسبة تجمع اليوم، أو ناتجها وحده، أو «الحساب كده»، أو رصيد نهاية اليوم، أو اتفاق الطرفين على رقم. هذا الإقفال هو نهاية اليوم وبداية ما بعده.
إن لم تجد إقفالًا في آخر ١٥٠ رسالة، تعود إلى الوراء (حتى ٩٠٠ رسالة). ويمكنك اختيار إقفال آخر من القائمة.

## الحساب النهائي (بصيغة آلة المحل الحاسبة)
تكتب الأداة في النهاية الحساب بصيغة رسائل المحل نفسها، جاهزًا للنسخ والإرسال، ويُقرأ من اليسار إلى اليمين:
```
1,171,035+22,150+…+6,850−311,000
=1,857,125
```
- عند التفاف السطر لا يُقسم أي رقم، ويبدأ السطر الجديد بإشارة الرقم (+ أو −).
- **كشف حساب في المحادثة** (آلة حاسبة: صورة أو نص): يصبح نقطة البداية. الرقم الأول = الرصيد السابق، والناتج = الرصيد الجديد.
  تطابق الأداة كل بند في الكشف مع المحادثة: ✓ موجود، أو «قبل بداية المحادثة» (التصدير قد يبدأ من المنتصف، وهذا ليس خطأ)، أو ⚠️ غير موجود / زائد عن الكشف، وتتحقق من صحة الناتج.
- **التحويل على عدة إيصالات**: ١٨٠٠ + ٣٠٠٠٠ + ١٨٢٠٠ ثم «تم ٥٠٠٠٠ محمد ابراهيم» = بند واحد قدره ٥٠٬٠٠٠. وكذلك «تم» ردًّا على طلب العميل («39930»، و«40» بمعنى ٤٠٬٠٠٠).
- أي تحويلات بعد الكشف تُضاف إلى ناتجه: `1,857,125+20,000−7,125 =1,870,000`.

## ما الجديد في الإصدار ٢
- **أقل تكلفة وأسرع:** تُرسل القواعد وتعليمك مرة وتُخزَّن مؤقتًا (prompt caching)، فتدفع كل صورة بعد الأولى نحو ١٠٪ من تكلفتها.
- **رد مضمون الشكل:** يرد Claude بـ JSON ذي شكل محدد (structured outputs)، فلا تخمين في قراءة الرد.
- **أكثر أمانًا:** لا يقبل الخادم إلا مهام محددة (`image`، `text`، `closings`، `lessons`، `merge`)، فليس بوابة مفتوحة إلى Claude، والصفحة بلا سكربتات مضمّنة.
- **تحليل أسرع:** ٤ صور في وقت واحد، ودفعات النصوص بالتوازي.
- إصلاح: نماذج 5.5 ترفض المعامل `temperature`، فأُزيل.

## التشغيل على Netlify
1. Netlify ← Add new site ← Import from Git ← المستودع `elbshmds` ← **Base directory: `ai-tool`** ← Deploy.
2. Environment variables: `ANTHROPIC_API_KEY` (من console.anthropic.com، مع وضع حد شهري للإنفاق) و`APP_PASSWORD` (١٢ حرفًا أو أكثر). ثم Trigger deploy.
3. كل دفع إلى `main` ينشر الأداة تلقائيًا، ولكن فقط إذا تغيّر شيء داخل `ai-tool/`.
اختياري: `MODEL_FAST` / `MODEL_STRONG` لتغيير النماذج.

## على الحاسوب
1. Node.js 22 أو أحدث. انقر نقرًا مزدوجًا على `start-local.cmd` (في المرة الأولى يثبّت المتطلبات وينشئ `local/config.json`).
2. في `local/config.json`: `password`، و`engine` = `anthropic` (مع `anthropicApiKey`) أو `ollama` (دون إنترنت: `ollama pull qwen2.5vl:7b`).
3. افتح `http://localhost:8787` (أو عنوان الحاسوب من الهاتف على شبكة الواي فاي نفسها).

## داخل موقع المحل
`elbshmds-ai-page.html`: غيّر `TOOL_URL` إلى رابط Netlify، وأضف عنوان حاسوب المحل إلى `frame-ancestors` في `netlify.toml`.

## الأمان

- لا تُحفظ المحادثات ولا الصور؛ يُحفظ فقط القواعد والتصحيحات.
